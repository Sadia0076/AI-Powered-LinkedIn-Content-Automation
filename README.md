# 🚀 DLeaders — AI-Powered LinkedIn Content Automation

> **Automating the complete journey from professional news discovery to LinkedIn publishing.**

🎥 **[Watch the Loom Demo →](https://www.loom.com/share/6ad57a560ee14a999a9ad4367d689359)**

## 🎯 Problem

Creating consistent LinkedIn content requires manually finding news, researching it, writing posts, designing graphics, publishing, and tracking results.

I built an **end-to-end AI automation pipeline** to eliminate this repetitive work.

## ⚙️ How It Works

**Phase 1 — News Discovery** 🔎
Google News RSS → AI filtering → relevant professional news.

**Phase 2 — AI Content Generation** 🤖
LLM generates headlines, supporting text, captions, hashtags, and structured content.

**Phase 3 — Automated Image Generation** 🎨
FastAPI + Python generates branded LinkedIn visuals and stores them in Google Drive.

**Phase 4 — LinkedIn Publishing** 🚀
Ready content and images → LinkedIn → automated status and error tracking in Google Sheets.

```text
News → AI Filtering → AI Content → Branded Image → LinkedIn → Tracking
```

## 🛠️ Tech Stack

**n8n • Python • FastAPI • LLM/Groq • Google News RSS • Google Sheets • Google Drive • LinkedIn API**

## 💡 Key Engineering Highlights

* Built a **4-phase modular automation architecture**
* Integrated multiple external APIs and cloud services
* Implemented **AI-based content generation and classification**
* Used FastAPI to overcome n8n Cloud's Python package limitations
* Added **status-based processing and error handling**
* Designed the workflow to be reusable for future posts, not just a single example

## 📈 Business Impact

The system transforms a highly manual content process into an **automated, scalable, and trackable workflow**, reducing repetitive work while enabling consistent professional content production.
